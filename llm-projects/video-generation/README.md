# Video Generation Demo

A Python demo project that takes a text prompt from the console.

## Features

- Interactive console input for video prompts
- Simple string input handling

## Prerequisites

This project requires Python 3.8 or higher.

## Installation

1. **Navigate to the project root:**
   ```bash
   cd /path/to/llm-for-nuts
   ```

2. **Install Python dependencies from root requirements.txt:**
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the script and enter a prompt when prompted:

```bash
python llm-projects/video-generation/video_generator.py
```

Example interaction:
```
Enter your video prompt: A beautiful sunset over the ocean
Prompt received: 'A beautiful sunset over the ocean'
```
